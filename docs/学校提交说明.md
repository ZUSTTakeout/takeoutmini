# 校园美食街项目提交说明

## 一、项目内容

本项目包含：

- 微信小程序前端：`apps/miniapp`
- 后端 API：`apps/api`
- 数据库结构：`apps/api/prisma/schema.prisma`
- Docker 配置：`compose.yaml`
- 小程序导入文件：`apps/miniapp/dist/build/mp-weixin`

## 二、演示方法

1. 安装并打开 Docker Desktop。
2. 在项目根目录运行：

   `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-local.ps1`

3. 检查后端：打开 `http://127.0.0.1:3000/api/health/live`，看到 `{"status":"ok"}` 即可。
4. 打开微信开发者工具，导入 `apps/miniapp/dist/build/mp-weixin`。
5. 点击“编译”进行演示。

## 三、项目说明

本版本用于课程、比赛或学校验收演示，已包含店铺浏览、商品查看、购物车、下单、订单查看和取消等主要流程。正式上线还需要配置真实微信 AppID、合法 HTTPS 域名和生产数据库。

## 四、提交注意

- 不提交 `.env`，其中包含本地密码和密钥。
- 不提交 `node_modules`，依赖可按 README 重新安装。
- 提交源码包和小程序构建目录即可。
